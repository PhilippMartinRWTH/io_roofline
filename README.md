# Task-Aware I/O Roopline Modelling: Bridging the Gap Between Application Patterns and HPC Filesystem Performance

## Reproduction
To reproduce the experiments, install [mdtest](https://github.com/hpc/ior) and the [ESI-OpenCFD](https://www.openfoam.com/) version 2406 of OpenFOAM.
Then, refer to the SLURM Scripts.
Note that you will have to adjust paths.

## Data
The data/ directory contains all measurement data relevant for the submission and plotting scripts to create different plots.

## SLURM Scripts
The `slurm_scripts` directory contains sample scripts of how the data was generated.
